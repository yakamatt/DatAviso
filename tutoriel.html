1 · Les clausiers

Vos textes types, en un clic sur Aviso

Sur chaque ligne dont le Référentiel porte un code (GN 4, CO 24…), des icônes apparaissent au-dessus de « Dispositions réalisées ». Un clic ajoute le texte à la suite de ce qui est déjà écrit, rien n'est remplacé. Survolez une icône pour relire le texte avant de l'insérer.

Clausier Personnel

Vos propres textes, rangés dans votre navigateur. À déclencheur égal, il passe avant le Clausier Commun.

  • Créer le « + » gris, sur une ligne sans snippet personnel, enregistre le texte de la cellule comme votre snippet pour ce code
  • Insérer le texte l'icône jaune, qui prend ensuite la place du « + »
  • Modifier le crayon jaune, sans quitter Aviso. Tous vos snippets sont aussi dans popup › 📒 Modifier le Clausier Personnel

💾 Il vit dans votre navigateur : exportez-le de temps en temps (Paramètres › Clausier Personnel).

Clausier Commun

Les textes partagés par l'équipe, dans un Google Sheets, mis à jour automatiquement.

  • 📄Créer une ligne dans le tableau partagé : popup › 📄 Consulter le Clausier Commun
  • Insérer le texte l'icône bleue, sur les lignes dont le code a un texte commun
  • ✏️Modifier directement dans le même tableau ; le changement arrive chez tous à la mise à jour suivante

Boutons Réglementation

Ils ouvrent l'article de la ligne dans un nouvel onglet, sur sitesecurite.com et sur Légifrance : trames ERP, Habitation et BUP (code du travail), et Légifrance seul pour l'accessibilité HAND. Ils s'affichent même sans snippet. Paramètres avancés › Liens réglementaires choisit les sources de chaque trame.

Bonus · Au clavier

Tapez un déclencheur, il devient un texte

Chaque snippet a un déclencheur, comme /GN4. Tapez-le dans n'importe quel champ (Aviso, champ Remarque compris, Gmail, formulaires…) : après une courte pause, il se remplace tout seul par son texte. {date} et {time} deviennent la date et l'heure du jour.

2 · Améliorations ergonomiques Aviso

Votre affaire à portée de clic

Ouvre les dossiers relatifs à votre affaire

À partir du numéro d'affaire, trois liens :

  • SGO la fiche de l'affaire dans SGO
  • ShP la recherche du numéro dans SharePoint
  • C:\ la recherche dans l'Explorateur Windows

Sur la liste Plans Affaires et dans la barre bleue d'une affaire ouverte. Chacun se désactive dans Paramètres avancés.

Un clic sur le titre copie le numéro

Cliquez sur le titre de l'affaire, dans la barre bleue : son numéro est copié, prêt à coller dans un courriel ou une recherche.

Et le titre devient sélectionnable à la souris : glissez dessus pour copier l'intitulé complet.
